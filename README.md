# 🌤️ News & Weather Dashboard

## 📌 Description
React dashboard application integrating news and weather APIs to display real-time updates with dynamic UI and search functionality.

## 🚀 Tech Stack
- React.js
- JavaScript
- Fetch API
- CSS
- AOS (Animate On Scroll)
- Vite

## ✨ Features
- Fetch latest news using News API
- Display real-time weather data using OpenWeatherMap API
- Search functionality for different cities
- Dark mode toggle for better user experience
- Responsive design for mobile, tablet, and desktop
- Smooth animations using AOS
- Loading indicators and error handling

## ⚙️ Run Locally

```bash
git clone <repository_url>
cd news-weather-dashboard
npm install
npm run dev
```
